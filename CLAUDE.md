# Agent entry point

Grenadiers is a Rust/React multiplayer game. Read `CONTRIBUTING.md` and `README.md`
first. Canonical topic references are `docs/architecture.md`, `docs/testing.md`,
`docs/security.md`, `docs/dependencies.md`, and `api-guidelines/API-GUIDELINES.md`.
Read `e2e/README.md` for Playwright work. Keep behavior, contracts, tests, and relevant docs
in the same change. Do not duplicate these conventions in agent-specific documents.

Use root `BACKLOG.md` for open work/status and `docs/README.md` for topic ownership. Read the
relevant feature guide before changes; historical records are evidence, not new approval gates.
