# Baseline rule coverage

Scope: the initial two-human Grenadiers profile in [rules.md](rules.md), RULE01–RULE42.
The historical weapon/mob catalog does not expand this baseline. The matrix records meaningful
assertions at their appropriate layer, rather than requiring a browser test for every rule.

A source/assertion audit initially identified three partial cases: integrated bomb-order results,
offline vulnerability through the original fuse, and a safe assisted turn entering fire. The
v0.3.10 follow-up adds these regressions without changing production behavior. Independent closure
review and final release gates are recorded in [verification](../verification.md).

`Covered by composition` identifies related checks across layers. RULE12 is conditional planner
coverage: normal baseline actors die in existing fire before their placement phase. None of these
rows establishes a human playtest, measured latency/browser envelope, restart recovery or v0.4.0
readiness. A test reference uses `path:test_name`; paths are relative to the repository root.

## Evidence boundaries

The full server gate exercises the simulation, real runtime, owner lifecycle and private replay.
Separate browser acceptance covers generated pickups, full match/rematch, full-state reconnect,
connected takeover and late rejection through Compose and Kubernetes. Personal capability frames
are excluded from persisted traces; public screenshots and redacted diagnostics remain available.

Hidden-document input clearing has component coverage and v0.3.12 adds actual headed Chromium
hidden/visible transitions, authoritative stopping and fresh-input recovery. Long-term background
throttling, suspension, delayed-network support and human playability remain separate M7 work. The implementation plan's release checklist remains
required even when every rule row has a test. Replay comparisons inspect private world, lifecycle,
input and pending-report facts, with explicit incomplete/truncated evidence; they do not claim
exhaustive exploration of every possible command history.
