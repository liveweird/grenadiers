# Hard nearby farming opportunity — 2026-11-05

## Decision and boundary

The ordered seed53 comparison showed a common opening basis choosing a distance-16 opponent
pursuit instead of a distance-2 productive Farm. Hard70 adds a bounded fresh-choice stage while
retaining Hard69 progress accounting and the existing physical execution proofs.

The original total order remains intact. Only a score-4 opponent Attack winner is considered;
any eligible Collect candidate vetoes Farm promotion. Otherwise the first Farm in the existing
order wins only when its score per distance-plus-one is strictly greater. Ties retain Attack;
attacks at distance zero or one cannot lose to the current Farm score. No hidden drop value is
inferred. A pairwise ratio comparator was rejected because score-4 equipment creates a real
nontransitive ordering cycle.

Promotion runs only for new, invalid/deferred or stalled replacement goals. The stalled target
is excluded; no-alternate fallback stays identical. Valid retention and BetterOpportunity rules
remain unchanged, including the 120-tick commitment. The scan receives at most 512 work units
and one sixteenth of remaining work; partial analysis charges spent work and preserves baseline.
No new BFS, forecast, RNG draw or certificate capability is introduced. Earlier profiles retain
legacy choices; Replay39 binds Easy68/Standard62/Hard70 and Replay38/37 remain intact.
