# Round camera examples

Native Three.js captures show the normal framing and a sample from the left-rotation intro.
The actual effect moves smoothly into the normal view; zoom and right-rotation alternatives
use the same short, bounded presentation. Reduced motion keeps the normal view stationary.

- [Normal view](round-camera-neutral.png)
- [Opening rotation](round-camera-rotation.png)
