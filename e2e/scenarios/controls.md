# Configurable keyboard controls

## Scenario: custom controls persist and drive only their assigned native keys

Two real Chromium contexts open the active v4 interface at desktop and 320-pixel widths. The
desktop player changes East to physical KeyL and Bomb to Enter through the localized dialog,
which exposes five actions and no Equipment row, then reloads and sees the saved preference. The
help explains contact-activated Punch. A live two-player round proves default E emits no command,
ArrowRight no longer moves that actor, KeyL does move it, and holding Enter emits one Bomb command.
Restoring defaults through the interface survives another reload. The Polish narrow dialog remains contained and
both dialogs pass Axe. Screenshots retain the Polish 320-pixel dialog and restored desktop view;
framework traces stay disabled because admission traffic contains private capabilities.
